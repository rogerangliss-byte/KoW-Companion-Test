# KoW Companion v4.5.0 TEST1 — Release Notes

**TEST BUILD — NOT LIVE**

v4.5.0 TEST is rebuilt from the stable v4.4.0 English Live baseline and adds native working-state persistence, corrected Legendary chest logic, Resource Optimiser and Multi-Officer Planner improvements, and the approved Central Inventory order.

## Key changes
- Selected Officer, Progress/Compare filters and Planner working state persist across normal refreshes.
- Legendary Officer Badge Chest = either 1 Universal Legendary Badge or 600 ORV.
- Legendary Officer Badge Selection Chest = 1 eligible specific Legendary Officer Badge only.
- Central Inventory follows the approved Order in List numbering.
- 50 XP Book removed; valid XP Books are 100 through 50,000 as documented.
- In-app Help, README and User Guide updated for v4.5.0 TEST.

## QA gate
Do not promote to Live until refresh persistence, chest calculations, Inventory ordering, backup/restore, navigation/stability and version reporting have all been tested successfully.
