# KoW Companion English v4.3.53 TEST

## Planner saved-progress integration
- Planner now uses the same saved Officer Progress calculation as the Progress dashboard.
- MAXED Officers show 0 badges needed and receive no shared-resource allocation.
- In-progress Officers use their calculated saved badge shortfall rather than automatically needing the full badge total.
- Individual Officer Badges are then applied to that remaining requirement.
- Full held badge inventory remains displayed and is never consumed by Planner.
- MAXED is shown as its own Planner status and summary count.
