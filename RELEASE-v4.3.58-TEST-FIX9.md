# KoW Companion English v4.3.58 TEST Fix 9

## What's New
v4.3.58 introduces Advanced Multi-Officer Planning and Future Officer resource forecasting.

### Advanced Planner
- Analyse saved Officer Progress against shared Inventory.
- MAXED Officers are excluded.
- Planning Session:
  - Saved Officers only
  - All Officer sessions
  - Next Officer session
  - October — Rally / Garrison
  - January — Infantry
  - April — Tanks
  - July — Tank Destroyers
- Specific future sessions show only their projected target.
  - Example: April — Tanks -> S8 Tank — PROJECTED.
- Officer Session / Season filter:
  - All Sessions
  - Original
  - S2–S7
- Season and Officer Type work together.
  - Example: S6 + Tank.
- Optional Include Not Started and Include Original Officers controls.
- Top 10 results by default for larger Saved/All reports.
- Show all / Collapse controls.

### Future Officer resource planning
Established Legendary Officer requirements:
- 1 Officer: 1,600 badges; 98,000 Star value; 199,646,700 XP.
- 2 Officers: 3,200 badges; 196,000 Star value; 399,293,400 XP.

The Planner compares these requirements with held Inventory.

### ORV/SRV forecast
- Releases now labels the growth input as **Forecast increase per Officer release (%)**.
- Future ORV/SRV values are calculated as forecasts and clearly labelled FORECAST.
- Actual published costs should replace forecasts when known.

### Releases integration
- Future Officer Cost Forecast includes an Advanced Future Officer Planning explanation.
- Added **Open Advanced Planner** shortcut.

### Recommended workflow
1. Inventory first.
2. Enter and save Officer progress.
3. Verify Progress statuses.
4. Review Releases forecast.
5. Run Advanced Planner.
6. Review resource readiness/shortfalls before committing flexible resources.

### Safety of saved data
Advanced Planning is preview-only. It does not spend Inventory or modify saved Officer progress.
