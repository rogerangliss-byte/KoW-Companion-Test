# KoW Companion v4.4.0 TEST 1 — Planning Readiness Dashboard

## New
- Adds a Planning Readiness Dashboard immediately below Future Officer Targets & Saved Scenarios.
- Uses the existing saved Planning Scenario data; no data migration is required.
- Shows Badge, Star and XP readiness percentages for each saved target.
- Shows an overall readiness percentage using the limiting resource.
- Highlights the lowest-readiness saved scenario as the Priority Target.
- Gives a simple Suggested Next Action based on the first resource shortfall.
- Includes Open in Planner to reload the existing saved scenario.

## Scope
This is an English Test prototype only. No English Live or Multilingual repository is changed.
