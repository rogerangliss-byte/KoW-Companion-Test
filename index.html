❓ Help & Instructions

✨ What’s New — v4.3.31

v4.3.30 focuses on faster Officer progress entry, clearer progress tracking, and the new four-strand skill system.

📊 Officer Progress

Officers are automatically classified as MAXED, IN PROGRESS, or NOT STARTED. The main Progress filters and Compare Officer Progress filters work independently.

🔎 Compare Officer Progress

Compare saved Officers in Season order. You can compare Not Started and In Progress Officers even when the main Officer Progress table is filtered differently.

✏️ Edit Officer Progress

The Officer tab now has Edit Officer Progress, allowing you to enter the key Officer-specific values in one place: Current Star Level, Current Officer Level, Officer Unlocked, Skill Strands and Training Level.

⭐ MAX Officer

Use MAX Officer to set the selected Officer to 5★, Level 70, Unlocked, all four Skill Strands at Level 5, and Training Level 180.

✅ Automatic Unlock

Setting an Officer above Level 1 automatically selects Officer unlocked, reducing the chance of missing the unlock status.

🎚 Exact Training Level

Training can now be entered as an exact number from 0–180 as well as using the slider.

🧩 Four Independent Skill Strands

Each Officer has four independent Skill Strands. Every strand begins at Level 1 free and can be advanced separately to Level 5. Combinations such as 1 / 3 / 5 / 2 are supported.

The 16 paid skill increases share one badge-cost sequence, regardless of which strand is increased:

10, 10, 15, 15, 30, 30, 40, 40, 45, 45, 50, 50, 75, 75, 80, 80

All 16 paid skill increases cost 690 Officer Badges in total.

ℹ️ Skill Cost Information

The Development screen now shows Next Cost, badges used / 690, and badges remaining. Select the i button to view the full cost sequence and current strand information.

🎨 Skill Progress Colours

Gold means that skill level has been reached. Black/dark means it has not yet been reached. Level 1 is gold because it is free and already available on every strand.

💾 Improved Saving & Synchronisation

Progress saved through Edit Officer Progress is written back to the Officer profile so the Officer, Stars, Develop, XP and Progress views stay synchronised.

Recommended workflow: work through Officer → Stars → Development → XP → Planner, then use Save Progress. Use Backup & Restore in Settings before major changes or when you want a portable copy of locally saved app data.

1. Officer

Use Search, Season and Officer Type / Role filters to narrow the Officer list. Select the Officer you want to calculate. A matching portrait is displayed automatically when its file is available in the officer-portraits folder.

The selected Officer determines the cost of an Officer Badge in Officer Readiness Vouchers (ORV) and the cost of an Exclusive Star in Star Readiness Vouchers (SRV).

The Officer Upgrade Summary shows the remaining Officer Badges, Officer Stars and Officer XP for the currently selected Officer.

Original Officers: Officer Readiness Vouchers (ORV) and Star Readiness Vouchers (SRV) cannot be used for Original Officers.

2. Stars

Set the Officer's current and target Star level. Enter Legendary Star I, II and III held and Star Readiness Vouchers (SRV) held. The app calculates Officer Star value held, Exclusive Stars obtainable from SRV and the remaining Star requirement.

3. Development

Enter unlock status, the four independent Skill Strand levels and Training Level. Then enter Officer Badges Held, Universal Legendary Badges Held, Legendary Officer Badge Selection Chests Held and Officer Readiness Vouchers (ORV) Held.

Each Universal Legendary Badge is worth 1 Officer Badge for a Legendary Officer.

Each Legendary Officer Badge Selection Chest can be used as either 1 Universal Legendary Badge or converted to the latest-Season Officer Readiness Voucher (ORV) value. A chest cannot count as both. With the current S7 database the benchmark is 600 ORV per chest.

4. XP

Enter current and target Officer Level, then enter the number of Officer XP Books held in each denomination. The app calculates XP held, XP required and the remaining shortfall.

5. Planner & Resource Optimiser

Use Planner after entering Stars, Development and XP. Select a goal such as Max Officer, Next Star, Reach 5★, Max Skills or Max Training to see requirements, resources held and shortfalls.

The Resource Optimiser lets you select a second Officer in Compare with Officer. It compares the Officer Readiness Voucher (ORV) cost per Officer Badge for the two Officers.

How to interpret the recommendation: where both Officers can use ORV, the optimiser recommends favouring ORV on the Officer with the lower ORV cost per badge and favouring shared Universal Legendary Badges / Legendary Officer Badge Selection Chests on the Officer with the higher ORV cost per badge. This protects the more expensive Officer from unnecessary ORV spending.

The optimiser is preview only. It does not automatically spend, allocate or change your saved resources.

5a. Multi-Officer Upgrade Planner

The Multi-Officer Planner lets you create a priority list of several Officers, set the Officer Badges still needed for each, and preview how shared ORV, Universal Legendary Badges and Legendary Officer Badge Selection Chests could cover the plan.

Use Use current held resources to copy the resources currently entered in Development. Plans are preview-only and do not spend or alter the normal calculator data. Named plans can be saved locally in the browser and loaded again later.

6. Save Progress

MAX Officer: use the ⭐ MAX Officer button to set the selected Officer to 5 Stars, Level 70, Unlocked, all 4 Skill Strands at Level 5 and Training Level 180. The Officer profile is saved immediately. Shared inventory is not spent or changed.

Use Save Progress after entering or changing calculator information. Progress is stored locally in the browser on the current device. Save Progress does not publish your personal data to other users.

7. Database

The Database Manager controls the Officer master list. Use it to add or edit Officers and export the database. Export CSV exports the Officer database; it is different from Save Progress and App Backup.

To publish new or edited Officers for everyone, update the published officers.json and officers.csv files in the GitHub repository.

7a. Recurring Release Calendar

The Releases tab shows the recurring August → July annual KoW release cycle. The current month and next scheduled release are highlighted automatically, so the calendar does not require a yearly reset.

8. Settings, Backup & Restore

Settings contains the app name, portrait and landscape backgrounds, update controls and Backup & Restore.

Export App Backup creates a JSON backup of KoW Companion data stored locally by the browser. Keep this file somewhere safe. Restore App Backup loads a previously exported JSON backup and reloads the app.

Check for Updates compares the installed version with the published version. Refresh Latest Version refreshes the KoW Companion application cache without intentionally deleting saved calculator progress.

SRV = Star Readiness Voucher
Universal Legendary Badge = 1 Officer Badge for a Legendary Officer
Exclusive Star = 110 Officer Star value
