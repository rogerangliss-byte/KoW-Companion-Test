📘 v4.3.58 — Advanced Planning & Future Officer Forecasting Guide

What’s New in v4.3.58

v4.3.58 expands KoW Companion from single-Officer resource tracking into advanced multi-Officer and future-session planning. It links your saved Officer progress, shared Inventory, recurring release schedule and projected future Officer costs so you can decide whether to finish current Officers or preserve resources for future releases.

  • Advanced Multi-Officer Planning with saved Officer analysis.
  • Future Officer Planning using recurring October, January, April and July release sessions.
  • Future Officer Type selection for Rally, Garrison, Infantry, Tank and Tank Destroyer.
  • Officer Session / Season filtering for All Sessions, Original and S2–S7.
  • Combined Season + Type reports, for example S6 + Tank.
  • Focused future-session reports: April — Tanks shows only S8 Tank — PROJECTED.
  • Projected S8 resources for one or two future Legendary Officers.
  • ORV/SRV forecasts linked to the Releases forecast growth setting.
  • Inventory-aware readiness using ORV, SRV, Universal Badges, Selection Chests, Stars and XP Books.
  • Top 10 compact results for larger Saved/All reports, with Show all and Collapse.
  • Releases → Planner shortcut for Advanced Future Officer Planning.
  • MAXED Officers excluded from Advanced Planner recommendations.

Recommended Flow

  1. Inventory first: enter and save the resources you currently hold.
  2. Officer: enter each Officer’s current progress and save the Officer profile.
  3. Progress: confirm Officers are correctly shown as MAXED, IN PROGRESS or NOT STARTED.
  4. Releases: review the recurring release schedule and set the forecast increase percentage.
  5. Planner: run Advanced Multi-Officer Planning using the session, season and type filters required.
  6. Review the forecast: compare current candidates with projected future resource requirements before committing flexible resources.

1. Prepare Inventory

Advanced Planning uses the same shared resource information as the rest of the app. Before running a report, update Inventory with your current ORV, SRV, Universal Legendary Badges, Legendary Officer Badge Selection Chests, Star resources and XP Books. XP is calculated from the quantities entered for each XP Book denomination.

The Planner is preview-only. Running or refreshing a recommendation does not spend, deduct or change Inventory.

2. Save Officer Progress

For each Officer you want included in current-Officer planning, open the Officer page, enter the Officer’s current Stars, Level, Skills, Training and Officer-specific resources, then save the profile. Advanced Planning reads the same Progress information used by the Progress screen.

MAXED Officers are always excluded from Advanced Planner recommendations because no further development resources are required for them.

3. Planning Session

The Planning session selector controls the overall purpose of the report:

  • Saved Officers only — analyse eligible saved/current Officers only.
  • All Officer sessions — combine projected future Officer scenarios with eligible saved/current Officers.
  • Next Officer session — plan for the next recurring future release session.
  • October — Rally / Garrison — focused future Rally/Garrison planning.
  • January — Infantry — focused future Infantry planning.
  • April — Tanks — focused future Tank planning.
  • July — Tank Destroyers — focused future Tank Destroyer planning.

When a specific future session is selected, the results intentionally show only that projected future Officer scenario. For example, April — Tanks shows S8 Tank — PROJECTED. Use All Officer sessions when you want projected Officers and saved/current Officers in the same report.

4. Officer Session / Season Filter

The Officer Session / Season filter narrows the saved/current Officer side of a report. Available choices are All Sessions, Original, S2, S3, S4, S5, S6 and S7.

Example: choose Saved Officers only → S6 → Tank to analyse eligible saved S6 Tank Officers only.

5. Future Officer Type

All applicable types / session default uses the Officer type expected for the selected recurring release session. You can override it with Rally, Garrison, Infantry, Tank or Tank Destroyer.

The type selector also works with the Season filter for saved/current reports. This enables focused reports such as S6 + Tank or S7 + Infantry.

6. Include Not Started / Include Original Officers

Include Not Started adds eligible Officers that are marked NOT STARTED. Leave it off when you only want active development candidates.

Include Original Officers allows Original Officers to be included where relevant. Original Officers remain subject to their own resource eligibility rules and should not be treated as seasonal ORV/SRV Officers.

7. Analyse Planning Session

Select the required options and press Analyse Planning Session. The summary explains the active session/filter combination and the recommendation. Refresh Recommendation recalculates the report using the latest saved Progress and Inventory.

For larger Saved Officers or All Sessions reports, the Planner displays the Top 10 results initially. Use Show all to display the full report and Collapse to return to the compact view.

8. Understanding PROJECTED Officers

A row such as S8 Tank — PROJECTED is a planning placeholder, not a published Officer record. It allows resources to be reserved before the actual Officer details are known. The projection does not add an unpublished Officer to the Officer Database and does not assume that forecast ORV/SRV costs are confirmed.

9. Projected S8 Resource Requirement

For projected Legendary Officers, the Planner shows resource requirements for both one Officer and two Officers.

10. ORV/SRV Forecasts

The Releases page field Forecast increase per Officer release (%) controls projected cost growth. The default shown by the app is a percentage, not a fixed number of ORV/SRV.

Future ORV/SRV figures are labelled FORECAST. They are estimates derived from the latest published cost baseline and the selected percentage/release distance. When actual future Officer costs are published, the published values should replace the forecast.

11. Releases → Advanced Planner

The Future Officer Cost Forecast section on Releases includes an Advanced Future Officer Planning note and an Open Advanced Planner button. Use it after reviewing a future release forecast to move directly to the Planner and compare the projected release against your saved resources.

12. Example — Planning for April S8 Tanks

  1. Update and save Inventory.
  2. Review Releases and confirm the forecast percentage.
  3. Open Advanced Planner.
  4. Select April — Tanks.
  5. Leave Future Officer Type on the session default, or select Tank manually.
  6. Run Analyse Planning Session.
  7. The focused result shows S8 Tank — PROJECTED.
  8. Review the one-Officer and two-Officer badge, Star, XP, ORV and SRV forecast.

13. Example — S6 Tank Development Report

  1. Select Saved Officers only.
  2. Select S6 under Officer Session / Season.
  3. Select Tank as Officer Type.
  4. Choose whether to include Not Started Officers.
  5. Press Analyse Planning Session.

The result contains only eligible S6 Tank candidates matching those settings.

Important Forecasting Notes

  • PROJECTED future Officers are planning scenarios only.
  • ORV/SRV forecasts are estimates until actual costs are published.
  • Inventory and saved Officer progress are never automatically spent by the Planner.
  • MAXED Officers are intentionally excluded.
  • Use Saved Officers only for current development decisions; use All Officer sessions for current-versus-future comparison; use a specific future session for a focused future-release report.

💾 Improved Saving & Synchronisation

Progress saved through Edit Officer Progress is written back to the Officer profile so the Officer, Stars, Develop, XP and Progress views stay synchronised.

Recommended workflow: start with Inventory and save the resources you currently hold, then work through Officer → Stars → Development → XP → Planner → Save Progress. Use Backup & Restore in Settings before major changes or when you want a portable copy of locally saved app data.

1. Inventory

Start here. Enter the resources you currently hold and press Save Inventory. Inventory is shared throughout the app, so you only need to maintain these resource totals in one place.

Inventory includes Officer Readiness Vouchers (ORV), Star Readiness Vouchers (SRV), Universal Legendary/Epic/Elite Badges, Legendary Officer Badge Chests and Selection Chests, Legendary/Epic/Elite Stars, XP Books, and individual Officer Badges.

For individual Officer Badges, enter quantities against the appropriate Officer. Each Officer's badge quantity is stored separately. Update Inventory whenever your in-game resources change, then save it before planning upgrades.

2. Officer

Use Search, Season and Officer Type / Role filters to narrow the Officer list. Select the Officer you want to calculate. A matching portrait is displayed automatically when its file is available in the officer-portraits folder.

The selected Officer determines the cost of an Officer Badge in Officer Readiness Vouchers (ORV) and the cost of an Exclusive Star in Star Readiness Vouchers (SRV).

The Officer Upgrade Summary shows the remaining Officer Badges, Officer Stars and Officer XP for the currently selected Officer.

Original Officers: Officer Readiness Vouchers (ORV) and Star Readiness Vouchers (SRV) cannot be used for Original Officers.

3. Stars

Set the Officer's current and target Star level. The Stars tab automatically follows the selected Officer rarity: Legendary, Epic or Elite Star I / II / III. Star Readiness Vouchers (SRV) are shown only for Legendary Officers and cannot be used by Epic or Elite Officers.

4. Development

Enter unlock status, the four independent Skill Strand levels and Training Level. Development uses the relevant saved Inventory resources when calculating what is available for the selected Officer.

Each Universal Legendary Badge is worth 1 Officer Badge for a Legendary Officer.

Each Legendary Officer Badge Selection Chest can be used as either 1 Universal Legendary Badge or converted to the latest-Season Officer Readiness Voucher (ORV) value. A chest cannot count as both. With the current S7 database the benchmark is 600 ORV per chest.

5. XP

Enter current and target Officer Level. Saved XP Book quantities from Inventory are used to calculate XP held, XP required and the remaining shortfall.

6. Planner & Resource Optimiser

Use Planner after entering Inventory and the Officer's Stars, Development and XP progress. Select a goal such as Max Officer, Next Star, Reach 5★, Max Skills or Max Training to see requirements, resources held and shortfalls.

The Resource Optimiser lets you select a second Officer in Compare with Officer. It compares the Officer Readiness Voucher (ORV) cost per Officer Badge for the two Officers.

How to interpret the recommendation: where both Officers can use ORV, the optimiser recommends favouring ORV on the Officer with the lower ORV cost per badge and favouring shared Universal Legendary Badges / Legendary Officer Badge Chests on the Officer with the higher ORV cost per badge. This protects the more expensive Officer from unnecessary ORV spending.

The optimiser is preview only. It does not automatically spend, allocate or change your saved resources.

7. Multi-Officer Upgrade Planner

The Multi-Officer Planner lets you create a priority list of several Officers, set the Officer Badges still needed for each, and preview how shared ORV, Universal Legendary Badges and Legendary Officer Badge Chests could cover the plan.

Plans are preview-only and do not spend or alter the saved Inventory. Named plans can be saved locally in the browser and loaded again later.

8. Save Progress

MAX Officer: use the ⭐ MAX Officer button to set the selected Officer to 5 Stars, Level 70, Unlocked, all 4 Skill Strands at Level 5 and Training Level 180. The Officer profile is saved immediately. Shared inventory is not spent or changed.

Use Save Progress after entering or changing Officer progress information. Progress is stored locally in the browser on the current device. Save Progress does not publish your personal data to other users.

9. Database

The Database Manager controls the Officer master list. Use it to add or edit Officers and export the database. Export CSV exports the Officer database; it is different from Save Progress and App Backup.

To publish new or edited Officers for everyone, update the published officers.json and officers.csv files in the GitHub repository.

10. Recurring Release Calendar

The Releases tab shows the recurring August → July annual KoW release cycle. The current month and next scheduled release are highlighted automatically, so the calendar does not require a yearly reset.

11. Settings, Backup & Restore

Settings contains the app name, portrait and landscape backgrounds, update controls and Backup & Restore.

Export App Backup creates a JSON backup of KoW Companion data stored locally by the browser. Keep this file somewhere safe. Restore App Backup loads a previously exported JSON backup and reloads the app.

Check for Updates compares the installed version with the published version. Refresh Latest Version refreshes the KoW Companion application cache without intentionally deleting saved calculator progress.
