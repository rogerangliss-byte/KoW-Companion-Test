❓ Help & Instructions

Recommended workflow: enter information in the order below, then use Save Progress to retain your calculator data on this device.

1. Officer

v4.2 Officer Experience: use Search, Season and Role filters to narrow the Officer list. The selected Officer's portrait is displayed automatically when a matching portrait file is available. Portrait files are stored in the officer-portraits folder. The app first looks for names such as officer-s7-romana.jpg or officer-katherine.jpg, with fallback support for older filename layouts., for example officer-s7-roisin.jpg.

Select the Officer you want to calculate. The selected Officer determines the cost of an Officer Badge in Officer Readiness Vouchers (ORV) and the cost of an Exclusive Star in Star Readiness Vouchers (SRV).

Original Officers: Officer Readiness Vouchers (ORV) and Star Readiness Vouchers (SRV) cannot be used for Original Officers.

2. Stars

Set the Officer's current and target Star level. Enter the quantities of Legendary Star I, II and III you currently hold and your Star Readiness Vouchers (SRV). The app calculates the Officer Star value held, Exclusive Stars obtainable from SRV, and the remaining Star requirement.

3. Development

Enter the Officer's current unlock status, completed Skill Points and Training Level. Then enter your Officer Badges Held, Universal Legendary Badges Held, Legendary Officer Badge Selection Chests Held, and Officer Readiness Vouchers (ORV) Held.

Each Universal Legendary Badge is worth 1 Officer Badge for a Legendary Officer.

Each Legendary Officer Badge Selection Chest can be used as either 1 Universal Legendary Badge or converted to Officer Readiness Vouchers (ORV). It cannot count as both. The ORV value is automatically linked to the highest Officer Badge ORV cost in the latest published Season. With the current S7 database this is 600 ORV per chest.

4. XP

Enter the current Officer Level and target Level, then enter the number of Officer XP Books you hold in each denomination. The app calculates XP held, XP required and the remaining shortfall.

5. Planner

Use the Planner after completing Stars, Development and XP. Choose a goal such as Max Officer, Next Star, Reach 5★, Max Skills or Max Training. The Planner combines the information already entered and shows requirements, resources held and shortfalls.

6. Save Progress

Use Save Progress after entering or changing your calculator information. Progress is stored locally in the browser on the device you are using. Saving progress does not publish changes to other users.

7. Database

The Database Manager controls the Officer master list. It can be used to add or edit Officers and export the database. Export CSV is different from Save Progress: it exports the Officer database rather than your personal calculator progress.

To make new or edited Officers available to everyone, the published officers.json and officers.csv files in the GitHub repository must be updated.

8. Settings

Settings contains the app name, portrait and landscape backgrounds, appearance controls and app-update controls. Check for Updates checks the published version. Refresh Latest Version refreshes the KoW Companion application cache without intentionally deleting saved calculator progress.

Terminology

ORV = Officer Readiness Voucher
SRV = Star Readiness Voucher
Universal Legendary Badge = 1 Officer Badge for a Legendary Officer
Exclusive Star = 110 Officer Star value
