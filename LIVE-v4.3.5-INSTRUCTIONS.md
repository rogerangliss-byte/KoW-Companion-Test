# KoW Companion v4.3.5 LIVE

This is the LIVE build.

## Important v4.3.5 behaviour

Shared resource inventory remains populated when switching Officers.

Shared across all Officers:
- Legendary Star I / II / III
- Star Readiness Vouchers (SRV)
- Universal Legendary Badges
- Legendary Officer Badge Selection Chests
- Officer Readiness Vouchers (ORV)
- XP Books

Saved separately for each Officer:
- Current and target Star level
- Officer unlocked state
- Skills 1–16
- Training level
- Officer-specific Badges held
- Current and target Officer XP level
- Planner goal

When leaving an Officer, the app automatically saves that Officer's progress before loading the newly selected Officer. The Save Progress button can also be used explicitly.

Reset This Officer resets only that Officer's saved progress and does not clear the shared resource inventory.
