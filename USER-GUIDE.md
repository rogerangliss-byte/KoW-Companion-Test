# KoW Companion v4.1.7 — User Guide

## Recommended order

### 1. Officer
Select the Officer first. The selected Officer determines the Officer Readiness Voucher (ORV) cost per Officer Badge and the Star Readiness Voucher (SRV) cost per Exclusive Star.

Original Officers cannot use Officer Readiness Vouchers (ORV) or Star Readiness Vouchers (SRV).

### 2. Stars
Enter the current and target Star level, Legendary Star I/II/III held, and Star Readiness Vouchers (SRV) held. The app calculates Star resources held and the remaining requirement.

### 3. Development
Enter unlock status, Skill Points, Training Level, Officer Badges Held, Universal Legendary Badges Held, Legendary Officer Badge Selection Chests Held, and Officer Readiness Vouchers (ORV) Held.

Each Universal Legendary Badge is worth 1 Officer Badge for a Legendary Officer.

Each Legendary Officer Badge Selection Chest can be used as either:
- 1 Universal Legendary Badge; or
- the current latest-Season Officer Readiness Voucher (ORV) value.

A Selection Chest cannot count as both. With the current S7 database, the benchmark is 600 ORV per chest.

### 4. XP
Enter current/target Level and quantities of each Officer XP Book. The app calculates XP held, required and shortfall.

### 5. Planner
After completing Stars, Development and XP, select a goal. Planner combines the entered resources and shows requirements, held resources and shortfalls.

### 6. Save Progress
Save Progress stores calculator information locally in the browser on the current device. It does not publish data to other users.

### 7. Database
Database Manager is for the Officer master list. Export CSV exports that database. To publish database changes for everyone, update officers.json and officers.csv in the GitHub repository.

### 8. Settings
Configure app name, portrait/landscape backgrounds and appearance. Check for Updates compares the installed and published versions; Refresh Latest Version refreshes the app cache while retaining locally stored progress.

## Terminology
- ORV — Officer Readiness Voucher
- SRV — Star Readiness Voucher
- Universal Legendary Badge — worth 1 Officer Badge for a Legendary Officer
- Exclusive Star — worth 110 Officer Star value
