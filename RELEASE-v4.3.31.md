# KoW Companion v4.3.31 LIVE

## Release summary
v4.3.31 promotes the tested single-season-name correction to LIVE while retaining the confirmed v4.3.30 Backup & Restore sync fix.

## Fixes
- Seasonal Officer names are no longer displayed with duplicated season prefixes.
- Progress save/reset and related Officer labels use the corrected display-name logic.
- Cross-device backup/restore continues to include individual Officer profile data, including Officer Badges Held.
- No Officer profile storage keys or backup JSON schema were changed by the v4.3.31 name fix.
